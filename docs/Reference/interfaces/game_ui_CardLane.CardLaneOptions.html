    プロパティ

    オプション 読み取り専用clip

    clip?: boolean

    はみ出したカードをマスクで切り抜くか。子ウィンドウの中で使うときに立てる——レーンの既定は 「隣接エリアの背景板が上から覆って隠す」で、周りに背景板が無い子ウィンドウでは通用しないため。

    • 定義 src/game/ui/CardLane.ts:42

    オプション 読み取り専用pinned

    pinned?: CardContent

    左端にピン留めするカード（ロケーションレーンの現在地）。

    • 定義 src/game/ui/CardLane.ts:37

    オプション 読み取り専用trailingPlaceholder

    trailingPlaceholder?: boolean

    並びの末尾に、カードを受け入れることを示す空枠を1つ出すか。カードを落とせる前詰めのレーンで立てる。 前詰めのレーンは中身が空だと何も描かれず、操作を受け付けるかどうかが見て分からないため。 固定枠のレーンは空き枠そのものが常に見えているので不要。
