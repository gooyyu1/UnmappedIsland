    オプション 読み取り専用identity

    identity?: readonly number[]

    内容を差し替えたときに「前と同じカード」だと分かるための識別子（映しているインスタンスのID）。 1枚が複数のインスタンス（スタック）を表すことがあるので集合で持ち、1つでも重なれば同じカードと みなす。省略したカードは差し替えのたびに別のカードとして扱われる。

    オプション 読み取り専用onTap

    onTap?: () => void

    カード全体を押したときの動作。持たないカードは押せない（押すと子ウィンドウを開くロケーションカード等）。
