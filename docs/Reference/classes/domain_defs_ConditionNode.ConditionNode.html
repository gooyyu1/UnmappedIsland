    クラス ConditionNode

    conditions（14節）の1ノード。actions/combinationsの一度きりの判定と、passivesの持続的なゲートが 同じ木を共用する。葉はproperty・slot_position・slot_content・object_tagの4種、複合はall/any/notの3種で、 kindに応じて使うフィールドが変わる（単一クラス+kindで判別）。

    property葉のみ有効。設定されていれば、リテラルvalue（values）の代わりに{object, prop}参照先の 現在の実効値と比較する（10.2節と同じ「リテラルか参照か」の二択）。in/not_inでは意味を持たない （ロード時エラー）。
