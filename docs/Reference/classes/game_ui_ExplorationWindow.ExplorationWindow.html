    クラス ExplorationWindow

    ロケーションカードから開く探索の子ウィンドウ。見つかったものの枠・探索率のバーと、 探索・閉じるのボタンを持つ。

    探索率が100%でも探索は続けられる（ExplorationSystem.md 2節）ため、探索ボタンは常に押せる。 100%で変わるのは「隠された道がもう見つからない」ことだけなので、それを補足の1行で伝える。

    • addFound(
          scene: Scene,
          metrics: ScreenMetrics,
          found: readonly CardContent[],
          viewport: Rect,
      ): void

      見つかったものを並べる枠。枠はFOUND_SLOTS個で固定し、収まらない分は横スクロールで送る。 枠からはみ出したカードは、レーンと違って背景板では隠せないのでマスクで切り抜く。

      カードは1枚をレーンと同じ形のまま、枠の幅に合わせて縮めて描く。
