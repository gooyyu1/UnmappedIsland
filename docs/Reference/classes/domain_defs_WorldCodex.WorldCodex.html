    クラス WorldCodex

    ロードされたYAMLファイル全体を表す集約オブジェクト（GameElementDefinition.md 3.1節）。 本体データ（ObjectDefTable）、5種の独立した名前空間（object/property/slot/tag/symbol）の NameRegistry、およびWellKnownPropertiesを持つ。ロード完了後は不変として扱う。 symbolNamesはシンボル型props（6節）の値の名前空間。実行時状態（WorldObject）は含まない （runtimeが担う）。
