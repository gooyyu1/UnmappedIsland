    クラス SaveSlots

    4スロット固定のセーブデータ置き場。

    一覧表示用のサマリーはスロット本体と別に持たない。持つと「本体を更新したらサマリーも更新する」 手順を呼び出し側が覚える必要が生じるため（SaveDataManagement.md 保存先節）。 空き判定はキーの不在だけで行い、別途「空きフラグ」は持たない。

    保存先はコンストラクタで受け取る。ブラウザではlocalStorage、テストではメモリ上の実装を渡す。
