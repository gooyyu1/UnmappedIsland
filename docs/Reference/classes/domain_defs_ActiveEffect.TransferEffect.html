      移動量は「出せる量」（PropertyValue.availableToTransferOut）とAmountの小さい方。allow_overflowが falseならさらに「受け取れる量」（remainingTransferCapacity）でも制限する。linked_add（9.5節）は 実際に移動した量に比例（amount * actual_moved / Amount、整数除算）してスケール適用する。 from/toが解決できない・対象がそのプロパティを持たない場合は何もしない。
