    クラス PlayerCharacter

    どのプロパティを持つべきかはまだ確定していないため、既存のサンプルに登場済みのものだけを実装している。

    take

    • take(item: WorldObject, session: WorldSession, gapIndex?: number): boolean

      アイテムを手持ちスロットへ入れる。手持ちが受け入れられなければ（accepts制約・6枠の上限）false。
