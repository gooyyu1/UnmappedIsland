    Class WorldObject

    WorldObject の一部（能動効果 set/add/destroy/spawn/transfer・actions/combinations・tick）。 効果の適用入口（ApplyActiveEffect）と対象解決、same_slot spawn の位置捕捉（EffectSite）・配置（Place）を持つ。 値の変更そのものは対象の PropertyValue へ、条件判定・抽選は Def 側の効果へ委ねる。
