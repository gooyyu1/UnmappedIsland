気候システム統計レポート

tests/diagnostics/climateStatsReport.test.ts によるシミュレーション実測値のスナップショット （シード数 20、各 3600 日）。core.yaml を変更したら以下で再生成する。

npm run stats:climate

計測方法

  • 序盤/中盤/終盤 = 各季節インスタンスの実持続期間の3等分区間。
  • 天気ごとの発生時間 = 期間内の合計時間。発生しなかった期間も0時間の標本として計上（nは全天気共通）。
  • 連続降雨/未降雨時間 = 同じ状態が連続した1回ごとの長さ。開始tickの区間に割り当て、季節境界で打ち切り。
  • 標準偏差は標本標準偏差（n-1）、5%ile/95%ileは最近隣法（nearest-rank）。
