# 地形生成統計レポート

`tests/diagnostics/terrainStatsReport.test.ts` による生成実測値のスナップショット
（シード 500 個）。`terrain_generation.yaml` を変更したら以下で再生成する。

```
npm run stats:terrain
```

## 計測方法

- 次数 = その土地に繋がっている道の本数。道は無向で、辺1本が両端の次数を1ずつ増やす。
- 余分な道 = 道の本数 − (土地数 − 1)。全土地を繋ぐのに最低限必要な本数（MST）を超えた分。
- 標準偏差は標本標準偏差（n-1）、5%ile/95%ileは最近隣法（nearest-rank）。

## 1日の移動時間

拠点を出て何箇所かを回り、拠点へ戻るまでの移動時間（ContentSkeleton.md 8.2節）。
計算は`src/analysis/dailyTravel.ts`。

その日どの土地に用があるかは定義から決まらないので、行き先の選び方を2通り並べる。
どちらを1日と読むかはContentSkeleton.md 8.3節が決める。

- **一様** — 拠点以外の土地から等しく選ぶ。どの土地にも同じだけ用があるとしたときの姿。
- **近い順** — 拠点から近い順に採る。同じものが近くでも採れるとしたときの下限。
- 回る順はその組で最も安いものを採り、土地の間は最短経路をたどる。
- 道を見つける探索時間は含まない（StartupReachStats.mdが持つ）。
