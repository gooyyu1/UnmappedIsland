# 地形生成統計レポート

`tests/diagnostics/terrainStatsReport.test.ts` による生成実測値のスナップショット
（シード 500 個）。`terrain_generation.yaml` を変更したら以下で再生成する。

```
npm run stats:terrain
```

## 計測方法

- 次数 = その土地に繋がっている道の本数。道は無向で、辺1本が両端の次数を1ずつ増やす。
- 余分な道 = 道の本数 − (土地数 − 1)。全土地を繋ぐのに最低限必要な本数（MST）を超えた分。
- 標準偏差は標本標準偏差（n-1）、5%ile/95%ileは最近隣法（nearest-rank）。
