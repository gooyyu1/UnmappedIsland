# 絵の無い型のレポートの読み方

数値は [`stats/card_art.yaml`](../../stats/card_art.yaml) にあります。
`tests/diagnostics/cardArtStatsReport.test.ts` が、定義（`src/assets/world-codex/*.yaml`）と
同梱の絵（`src/assets/objects/`）から数えたものです。型か絵を足したら再生成します。

```
npm run stats:card-art
```

**この文書は手書きで、再生成しても書き換わりません。** 持つのは読み方だけで、**数値そのものは
1行も書きません**（書けば、再生成したYAMLとずれます）。

## YAMLの節

| 節 | 中身 |
| --- | --- |
| `meta` | 札に自分の絵を映す型の数（`types`）、そのうち絵が在るもの（`drawn`）と無いもの（`missing`） |
| `missing` | 絵の無い型1つずつと、その型が名乗る絵の名前（`art`）。**全部の絵が揃えば空でもよい** |

**この表とYAMLが食い違うと `npm test` が赤くなります。**

## 数えている型

**札に自分の絵を映す型だけを数えます。** 判定は `src/analysis/cardArt.ts` の
`typesShowingOwnArtOnCard` が1箇所で持ち、次の型を外します。

- **生成型**——作りかけ・中身入り（[`GameElementDefinition.md`](../engine/GameElementDefinition.md)
  3.5節）。札には出ますが、映すのは素の型の絵です。
- **変種の軸の値**（同3.5.1節）——軸の先の変種へ trait を配るだけで、この型自身の個体は作られません。
- **世界そのもの**——すべての物を抱える根で、札になりません。

**`missing` の行は、1枚の絵ではなく1つの型です。** 1枚を共有する型（`art`、同4.3節）は、同じ `art` の
行として並びます。絵の無い型は種別の代役アイコンで札に出る（`src/game/view/cardLooks.ts`）ので、
ロードも画面も通ります——**足りていないことが見えるのはこの一覧だけです。**

## 見張り

**絵が揃っていないことは赤にしません。** 揃うまで `main` が赤いままになるので、このレポートは数を
出すだけで、`missing` が減っていくことが進捗です。

**型を足したのに絵が無いまま素通りすることはありません。** 鮮度の検査（丸ごと作り直して比べる）が
赤くなって再生成を求めるので、足した型はそこで `missing` へ現れます。絵を足したときも同じく
再生成を求められ、その型が `missing` から消えます。
