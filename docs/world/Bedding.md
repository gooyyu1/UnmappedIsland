# 寝床（敷物・寝台・詰め物）

## 概要

**守備範囲。** 眠る場所を決めます。地面に敷いた敷物から骨組みを組んだ寝台までを、何から作り、どう
組み合わせ、休息の回復へどう効かせるかまでです。

**境界。** 屋根・壁・住居そのものは [`Dwellings.md`](./Dwellings.md)。休息アクションそのもの
（`wait`/`rest`/`nap`/`sleep` の長さと回復量）は [`Characters.md`](./Characters.md) 休息節。葉を編む連鎖と
繊維から紐までの連鎖は既にあり、本書はその出口を1つ足すだけです。スキルの粒度は
[`Skills.md`](./Skills.md) 2節。

**実現方法。** **文法の新設はありません。** 寝床は土地の `fixtures` スロットに立つ `fixture` 1種で
（[`ExplorationSystem.md`](../engine/ExplorationSystem.md) 1節の3スロット）、骨組みと詰め物を差し込む
`structure` スロットを持ちます（[`GameElementDefinition.md`](../engine/GameElementDefinition.md) 7節）。
部品は `passives` の `modify`（同 8.3節）で寝床のプロパティへ寄与し、寝床自身が `nap`/`sleep` アクションを
持って `agent` の回復量を足します。導入する語彙は型 `bed` と、部品のタグ `bed_frame`・`stuffing` の3つです。
**ただし、部品の寄与を回復量へ届かせる部分だけは今の文法では書けません**（4節）。

**在処。** 定義は `src/assets/world-codex/bedding.yaml` を予定しています。材料はすべて既存で、編んだ葉は
`weaving.yaml`、紐は `fiber.yaml`、太い枝は `locations.yaml` にあります。

**確定度と実装状況。** 検討結果であり確定仕様ではありません。**全体が未実装です。** 未決事項は8節。

## 1. 寝床の型は1つで、段は部品の有無から生える

**「地面の寝床」「高床の寝台」「詰め物入りの寝台」を別々の型にしません。** 型は `bed` 1つで、骨組みと
詰め物を差し込む枠を持ちます。

```yaml
object_defs:
  bed:
    tags: [fixture]
    slots:
      structure:
        cells:
          - {accept: {tag: bed_frame}, max: 1}
          - {accept: {tag: stuffing}, max: 1}
```

理由は組み合わせの数です。型で表すと、骨組み（有・無）×詰め物（無・羽毛・植物繊維）で6つになり、素材を
1つ足すたびに掛け算で増えます。部品で表せば、型1つと部品3つのままです。これは
[`Dwellings.md`](./Dwellings.md) 2節が住居で採った形と同じで、住居と寝床で考え方を割らないためでもあります。

炉が `campfire` → `three_stone_hearth` → `stone_hearth` と型を分けているのは、**段ごとにスロットの構成
そのものが変わる**（器を載せる枠が生える）ためです。寝床の段はどれも「同じ場所の下と上に何を足すか」でしか
ないので、同じ扱いにはしません。

### 1.1 敷物は部品ではなく、寝床そのもの

**枠に入る部品は骨組みと詰め物だけで、敷物は `bed` を作るときに消費します。** 敷物は「そこが寝床である
こと」自体なので、差し替える対象になりません。骨組みは後から下へ差し込みます——
[`Dwellings.md`](./Dwellings.md) 3節が高床への変更で壁を外させるのと同じで、現実の手間（敷物をどけて杭を
打つ）とも一致します。

**専用の中間素材「筵」は作りません。** `woven_leaf` を3枚綴じたものを別の型にすると、使い道が1つだけの
素材が1つ増えます（[`SurvivalItems.md`](./SurvivalItems.md) 6節）。巻いて運べるという性質は、
`woven_leaf` を3枚持ち歩くことで既に満たされています。

## 2. 段

| 段 | 形 | 何が変わるか |
| -- | -- | ------------ |
| 0 | 地面に直に寝る | 基準線。`player_character` trait が配る `sleep` |
| 1 | 編んだ葉の敷物 | 圧迫と、地面への伝導 |
| 2 | ＋骨組み（高床） | **湿気・虫・浸水から一度に離れる。ここが最大の跳躍** |
| 3 | ＋詰め物 | 圧迫。ただし湿気には弱くなる（5節） |

**熱帯でも敷物に意味があります。** 地面はおよそ25℃で熱容量が無限に近く、横になっている間の熱の逃げ道は
空気より地面が主です。ただし南国で効く分の大半は保温ではなく、湿気・虫・圧迫です。そのため**素材は
「乾いていること」が厚みより重要**で、青い葉を積むのは恒久的な寝床になりません（7節）。

## 3. レシピ

```yaml
object_defs:
  bed:
    recipes:
      # 編んだ葉を3枚、端を重ねて広げる。道具も紐も要らない。
      spread:
        steps:
          - requires:
              - {object: woven_leaf, count: 3, consume: true}
            duration: 20

  # 寝台の骨組み。杭4本を打ち、縦材を渡し、簀の子を縛る。軽いがかさばる。
  bed_frame:
    tags: [item, bed_frame]
    props:
      weight: {value: 6600}
      # ヤシの葉と同じく、籠には入らない嵩にする。
      volume: {value: 24000}
    recipes:
      lashed:
        steps:
          - requires:
              - {object: thick_branch, count: 6, consume: true}
              - {object: cord, count: 3, consume: true}
            duration: 180
```

素材まで遡った手間は次のとおりです。**段2は刃物なしでは通せない**ので（この節の末尾）、**段1から
通した合計は680分**（刃物ありの140分＋540分）——1日ぶんの自由時間（814分。
[`ContentSkeleton.md`](./ContentSkeleton.md) 8節）の8割強です。

| 完成品 | 直接の材料 | 工程 | 素材から通した時間 |
| ------ | ---------- | ---- | ------------------ |
| 寝床 | 編んだ葉 ×3 | 20分 | 素手で290分／刃物があれば140分 |
| 寝台の骨組み | 太い枝 ×6、紐 ×3 | 180分 | ＋約540分（うち紐に360分） |

- 編んだ葉は、素手なら1枚90分、刃物で中軸を割れば60分で2枚とれます（`weaving.yaml`）
- 紐1本は糸2本、糸1本は繊維2束なので、紐3本で繊維12束＝アバカ6本ぶんです（`fiber.yaml`）
- **紐の消費は筏と正面から競合します。** 筏はロープ4本＝紐12本を要求する（`voyage.yaml`）ので、骨組みは
  その1/4にあたります。**この比を意図した緊張として残すかは8節**

刃物は骨組みには直接要りませんが、繊維を掻き取るのに要るため、実質は段2の前提です。

## 4. 休息へどう効かせるか

**寝床が自分で `nap`/`sleep` を持ち、キャラクタ側の同名アクションが基準線になります。**

```yaml
    interactions:
      nap:
        trigger: menu
        duration: 180
        add: {agent: {stamina: 48, wakefulness: 48}}
      sleep:
        trigger: menu
        duration: 360
        add: {agent: {stamina: 120, wakefulness: 96}}
```

**部品の寄与をこの回復量へ届かせる文法が足りません。** 部品は `modify` で寝床のプロパティを押し上げられ
ますが、`add` の量はリテラル数値しか受け付けません（`src/loader/parseActiveEffects.ts` の `parseAdds`）。
`weight` と `duration` は既に `{subject, prop}` を受け取れる（同 `parseWeight`、
[`GameElementDefinition.md`](../engine/GameElementDefinition.md) 10.2節）ので、**`add` の量に同じ読み手を
使えるようにするのが最小の変更**です。これが無いと、骨組みを差しても回復量が動きません。

**寝床が持つプロパティの名前と本数は未決です**（8節）。快適性1本にまとめると、骨組みは「同じ数字が少し
大きい」だけになり、地面から離れることの意味が消えます。少なくとも乾きと虫は分ける必要があります。

## 5. 詰め物は羽毛と植物繊維の2択にする

| 詰め物 | 取り分 | 弱点 |
| ------ | ------ | ---- |
| 羽毛 | 圧迫の緩和が最も大きい | 要る羽の数が莫大。湿気を吸って固まる。暑い |
| カポック・椰子繊維 | 量が集まる。湿気に強い | 羽毛ほど沈まない |

羽は既に `feather` として存在し（ヤケイの解体で1羽ぶん40g）、[`Animals.md`](./Animals.md) 10節が使い道の
候補に挙げています。**40g/羽で計算すると、枕（500g〜1kg）でヤケイ12〜25羽、敷布団（3〜5kg）で75〜125羽**
です。羽毛布団が水鳥で作られたのは1羽あたりの取れ高が桁で違うためで、この島では罠を回し続ける長期目標に
なります。枕を中間目標に置けます。

**どちらも目の詰んだ袋が要ります。** 粗い編み地では羽軸が抜けます。布（紡績＋機織り）は
[`SurvivalItems.md`](./SurvivalItems.md) 7節で対象外なので、受け皿はなめし革になります。ただし革は熱帯では
蒸れるため、詰め物の段はここで足を止める可能性があります。詰め物は湿気を吸って固まり黴びるので、天日に
干す手間も付きます（[`DurabilitySystem.md`](../engine/DurabilitySystem.md)）。

## 6. ハンモックは寝台の上位ではなく別系統

| | 寝台（骨組み＋敷物） | ハンモック |
| -- | -------------------- | ---------- |
| 材料 | 太い枝が主、紐は少し | **紐が主、木材ゼロ** |
| 置ける場所 | どこでも | 支点が2つ要る |
| 虫・湿気 | 強い | 最も強い |
| 伸ばしろ | 詰め物を足せる | 無い |

熱帯アメリカのハンモックは、背中の下を風が抜けることがそのまま利点になります（温帯では逆に欠点で、下へ
断熱を足す必要が出ます）。この島では素直に強い選択肢ですが、網を編むのに紐を大量に食い、支点2つを土地の
側へ要求するため、寝台と上下にはなりません。[`Dwellings.md`](./Dwellings.md) 4節が工法へ課した「どれも
全域で他を上回らない」を、寝床でも守ります。

支点をどう表すかが未決なので、レシピは置いていません（8節）。

## 7. 除外・保留にした要素

- **青い葉を積むだけの段。** 切りたての葉を地面に敷くのは一晩の即席としては実在の技術ですが、水を含んで
  いて体重で潰れ、2〜3日で腐るため、恒久的な寝床にはなりません。毎晩積み直す消耗品として表すことは
  できますが、**上の段（編んだ葉）が素手90分・道具も繊維も不要**なので、置いても選ばれません
- **枯れ草・乾いたヤシの葉を敷くだけの段。** 同じ理由で外します。編んだ葉より安い段を作っても、初日から
  編めること以上の意味が出ません
- **板と仕口で組むベッド。** [`Skills.md`](./Skills.md) 2節が指物・接合に挙げている「ベッド」はこれです。
  本書の寝台は縛って組むので木材加工の範囲（同 2.1節の切り分け）で、板のベッドは本書の段の外にあります
- **敷物の差し替え。** 1.1節のとおり敷物は寝床そのものなので、より良い敷物へ替える道は今のところ
  ありません。織り布が入るなら、そのとき敷物も部品へ移すことになります

## 8. 未決事項

- **寝床が持つプロパティの名前と本数**（4節）。快適性1本か、乾き・虫・圧迫へ分けるか。分けるほど工法の
  違いは出ますが、その数だけ部品の宣言が増えます。**寄与の届け先は `happiness` に決まりました**
  （[`Characters.md`](./Characters.md) 幸福度節）が、寝床からの寄与はまだ1本も入っていません
- **`add` の量にプロパティ参照を許すか**（4節）。許さないなら、部品の寄与を回復量へ届かせる別の道が要ります
- **雨。** 屋根の無い寝床は雨季にほぼ無価値です。雨から守られていることは `sheltered`
  （[`ContainerSystem.md`](../engine/ContainerSystem.md) 6節）が既に表していますが、それを宣言する場所は
  浅い洞窟だけで（[`Dwellings.md`](./Dwellings.md) 5.1節）、屋根を持つ住居は未実装です。今これを寝床へ
  効かせると、寝床の値打ちが洞窟を見つけたかどうかだけで決まります
- **部品をどう運ぶか。** 本書は骨組みを `item` にして手で運ばせていますが、[`Dwellings.md`](./Dwellings.md)
  の壁・屋根も同じ問題を持ち、あちらはまだ決めていません。揃えるべきです
- **紐の配分。** 骨組みの紐3本と筏のロープ4本（＝紐12本）の比を、意図した競合として残すか
- **ハンモックの支点。** 「木が2本ある土地」をどう表すか。土地のプロパティか、`fixtures` に立つ木か
- **蚊よけの煙。** 熱帯では枕元の焚き火は暖を取るためではなく煙で蚊を追うためのものです。寝床と炉を近くに
  置く動機として表すか
- **敷物と骨組みの劣化。** 編んだ葉は熱帯では腐り、葺き替えと同じ恒久的な手間になります
  （[`DurabilitySystem.md`](../engine/DurabilitySystem.md)）。ハンモックと詰め物が「腐りにくい」という
  現実どおりの優位を得るかは、これを入れるかで決まります
