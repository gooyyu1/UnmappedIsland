# スキル一覧

## 概要

本ドキュメントは、ゲームに実際に登場させるスキルの一覧です。スキルがどう伸び、どうレシピを解放するかの
**仕組み**は [`SkillSystem.md`](../engine/SkillSystem.md) が扱います。本書は「どんなスキルを、どの粒度で、
いくつ用意するか」という内容面だけを扱います。

アイテムの内容は [`SurvivalItems.md`](./SurvivalItems.md)・[`Containers.md`](./Containers.md)・
[`Dwellings.md`](./Dwellings.md) を参照してください。

本ドキュメントは検討結果であり、確定仕様書ではありません（`【確定】` の付いた節を除く）。2 節の 11 本は
`src/assets/world-codex/` に投入済みで、どこまで動くかは
[`SkillSystem.md`](../engine/SkillSystem.md) 概要にあります。未決事項は 6 節に整理しています。

## 1. 分類の軸は素材ではなく技術

スキルは、**どの行動同士が習熟を転移させるか**で切ります。「木工」のように素材で括ると、木の器を彫ることと
木の小屋を建てることが同じスキルになりますが、この2つは技術をほとんど共有しません。逆に、器を彫ることと
石を打ち欠くことは「削って形を作る」を共有します。

[`SurvivalItems.md`](./SurvivalItems.md) の備考欄にある「柄付け技術」「縫製」「編み」「火で炙って硬化」は、
いずれも素材のカテゴリを横断して繰り返し現れます。これがスキルの単位です。

## 2. 一覧

「系統」は、レシピを解放する**製作**系か、素材・機会へのアクセスを広げる**アクセス**系かの区別です
（[`SkillSystem.md`](../engine/SkillSystem.md) 8 節の未決事項）。

| スキル | 系統 | 最初の一歩 | 主に開けるもの |
| ------ | ---- | ---------- | -------------- |
| **石器** | 製作 | 石を拾って打ち欠く（道具不要） | 石の刃物、斧・ハンマーの頭、石鏃 |
| **繊維・編み** | 製作 | ヤシの葉を素手で編む（道具不要） | 糸、紐、ロープ、肩掛けの袋、編み籠、背負い籠、編んだ葉の衣類、葉を編んだ箱、くくり罠 |
| **木材加工** | 製作 | 石の刃物で太い枝を削る | 木の箱、そり、柄材、板（製材）、火硬化の掘り棒・槍 |
| **指物・接合** | 製作 | 斧で角材を作る | スツール、テーブル、本棚、ベッド、台車の車輪、高床の骨組み |
| **建築** | 製作 | 枝と葉で雨をしのぐ | 住居の各部品（[`Dwellings.md`](./Dwellings.md)） |
| **皮革** | 製作 | 小動物の皮を剥ぐ | なめし革、皮袋、なめし革の衣類、なめし革の背負い袋 |
| **料理** | 製作 | 焼く | 調理の全般（未設計） |
| **保存** | 製作 | 食べ物を天日に並べて干す（道具不要） | 干物、燻製、塩漬け |
| **火** | アクセス | きりもみ式で枯れ草に火をつける（道具不要） | 着火・保火・高温（＋火硬化、土器の本焼き） |
| **狩猟** | アクセス | 動物を観察する、くくり罠を仕掛ける | 生皮・獣骨・角・肉 |
| **採鉱・製錬** | アクセス | 鉱石を見つける | 青銅（→ 青銅器4種） |

### 2.1 木材加工と指物を分ける理由

どちらも木を扱いますが、**縛って組む**（木の箱は「木材 + 植物繊維」）のと、**削り合わせて組む**（荷重の
かかるテーブル・本棚はほぞが要る）のは別の技術です。用途で「家具」と括ると素材による分類に逆戻りするため、
接合の方法で切っています。

### 2.2 火と料理を分ける理由

火起こしは摩擦・火口・温度管理という物理的な技術、料理は食材と調理法の知識で、互いに転移しません。また
料理はレシピ数が最も多くなる見込みで、火に含めると「掘り棒を炙ると料理が上達する」という転移になります。

火が担うのは着火と温度であり、開けるレシピは火硬化と本焼きだけです。段は能力として表します。

| 段 | できること |
| -- | ---------- |
| 低 | 乾いた場所で焚き火をつけられる |
| 中 | 種火を保てる、湿気・風の中でもつけられる |
| 高 | 土器の本焼きに要る高温を出せる |

**このうち腕が直接動かすのは、低の「つけられる」だけです**（5 節の倍率）。保つ長さも高温も炉の側が
決めるので、腕は要りません（[`FireSystem.md`](../engine/FireSystem.md) 10 節）。

### 2.3 保存を料理から分ける理由【確定】

**干す・燻す・塩漬けは、料理とは別のスキルとして数えます。** 料理は「今日おいしく食べる」、保存は
「乾季まで持たせる」で、目的も覚えることも違います。同じ 1 本にすると、料理を伸ばすだけで保存も付いて
きて、乾季の攻略が 1 本道になります。分ければ、保存を選んだ人がその方向に強くなります。

**出どころ**: [#656](https://github.com/gooyyu1/UnmappedIsland/issues/656) の 6

## 3. 柄付けをスキルにしない理由

「紐で頭部を軸に固定する」技術は [`SurvivalItems.md`](./SurvivalItems.md) の7アイテムに共通しますが、
スキルにはしません。固有の素材も固有の入手経路も持たず、**入力は紐（繊維）・頭部（石器または製錬）・
軸（木材加工）だけ**だからです。

これをスキルにすると、柄付けを使うアイテムが全てグレード2以上であるため、伸ばす手段が自分自身に依存して
永久に開きません（[`SkillSystem.md`](../engine/SkillSystem.md) 3.2 節）。代わりに条件の連言で表します。

```yaml
石の斧: 石器 basic + 繊維・編み basic
青銅の斧: 採鉱・製錬 basic + 繊維・編み skilled
```

「刃を作れて、紐も作れるようになったら斧が作れる」が、そのまま柄付け技術の要求を表しています。

## 4. 配分

- **必須は石器と繊維・編みの2つだけ。** どちらも道具なしで立ち上がり、他の多くのスキルの前提になります
- **残り9つは選択。** 1回のプレイで実用域へ届くのは3〜4個の見込みなので、上げきれない分が残り、
  プレイごとに異なる進行になります
- **前半（最初の乾季まで）に届くのは** 石器・繊維・木材加工・火・狩猟・皮革・料理・保存・建築
- **後半に乗るのは** 指物・採鉱・製錬。どちらもコンフォート要素と結び付きます

皮革・指物・料理・建築が後半に厚いのは意図的です。乾季を攻略した後の圧力（メンタルの低下）に対する
対抗手段がコンフォートであり、それを支えるスキル群が後半に必要になるためです。

## 5. アクセス系は、重みへ掛かる倍率で効く

アクセス系（火・狩猟・採鉱）はレシピを開けません（2 節）。段の効き方は、**`pick` の重みへ掛かる
倍率**です。倍率は腕の持ち主が持ち（素は 1 ＝ 等倍）、自分では動かず、腕の段の `passives` が
`modify` で押し上げます。使う側は `weight` の `times`
（[`GameElementDefinition.md`](../engine/GameElementDefinition.md) 10.2 節）で掛けます。

| 腕 | 掛ける先 | 素の重みを持つのは |
| -- | -------- | ------------------ |
| **火** | 着火が成功する重み（[`FireSystem.md`](../engine/FireSystem.md) 3.1 節） | 火口（`ignition_chance`） |
| **狩猟** | 探索で獣に出くわす重み（[`ExplorationSystem.md`](../engine/ExplorationSystem.md) 2.1 節） | 土地（`<動物>_find`）と海区（`shoal_find`・`seabird_find`） |

倍率の刻みは 2 本で同じです（novice 1 → basic 1.5 → skilled 2 → expert 3）。腕ごとに変えると、同じ
`basic` が腕ごとに違う効きになり、11 本で段の境目を揃えている意味が消えます。

**掛かるのは「出くわす機会」の側だけです。** 狩猟の腕は獲る手からも伸びますが、そちらには掛かって
いません——直接突く 3 つの手（獣を殴る `strike`、海と群れへ突く `spear_sea`・`spear_shoal`）は
**武器と漁場**が重みを決めており、当てる腕を「気配に気づく目」と同じ倍率で表せるかが決まっていない
ためです（[#1488](https://github.com/gooyyu1/UnmappedIsland/issues/1488)）。海鳥を捕る `catch_seabird`
は `pick` そのものを持たず（必ず獲れる）、掛ける先がありません。

- **素の重みは相手が持ち、腕は倍率だけを持ちます。** 枯れ草とヤシの実の皮で火の付きやすさが違うのは
  火口の差、荒野とジャングルで獣に出くわす頻度が違うのは土地の差です。**腕の側に相手ごとの値を
  書かないので、火口や土地が増えても腕は 1 行も変わりません。**
- **掛ける相手が 0 なら 0 のままです。** 居ない獣には、腕がいくら高くても出くわしません（土地が
  宣言していない候補は抽選から外れる）。**腕が増やすのは獣そのものではなく、居る獣に気づく確率です。**
- **そのぶん、実りの出る割合は下がります。** 押し上げるのは獣の候補の重みだけですが、卓の合計が
  増えるので他の候補の相対確率は落ちます——ジャングルなら実りの出る割合が約 91% から `expert` の
  約 77% へ。**腕を上げた探索は獣へ寄る**、が加算式を 1 つも書かずに出ます。
- **和ではなく積にするのは、荷重が押し上げる `pace`（[`Characters.md`](./Characters.md) 荷重の効き方節）
  と同じ理由**です。相手ごとの素の値が、そのまま効きの大小として残ります。
- **狩猟は罠には効きません。** 罠の抽選は誰も操作していない場面で走るため、罠から腕の持ち主が
  見えません（[`TrapSystem.md`](../engine/TrapSystem.md) 8 節）。動かせるのは出くわす機会の側だけです。
- **採鉱・製錬には掛ける先がありません。** 鉱石も製錬もこの島にまだ無いので、倍率も持たせていません。

### 5.1 見せ方は、段の名前だけ

**倍率の値は画面に出しません。** 出すのは段の名前と段内進捗だけ
（[`SkillSystem.md`](../engine/SkillSystem.md) 5 節）で、腕が上がったことは**結果の頻度**として現れます。
バーも数字も増えません。

出せる 1 つの数字が無いからです。実際の成功率は「素の重み × 倍率 ÷ 卓の合計」で、火口ごと・土地ごとに
違います。倍率（×2）だけを出せば読み手はそれを成功率として受け取り、成功率を出すなら火口と土地の一覧を
腕の隣に並べることになります。

**腕前の詳細には「与えている影響」の記号が 1 つ並びます**（[`Windows.md`](../ui/Windows.md) 8 節）。
`modify` を持つプロパティなら何であれ並ぶ仕組みが、そのまま拾ったものです。値ではなく相手の記号
だけなので、上の「1 つの数字を出さない」とは食い違いません。
