# 道具・武器・容器・衣類 アイテム案

## 概要

一人でのサバイバルという前提のもと、実在の原始技術を参考にしつつ、過度に高度な技術（紡績・機織り、製鉄など）は
除外し、「手が出せる範囲で便利・快適なもの」に絞ったアイテム案です。グレードは各カテゴリ2〜4段階に留め、
必要な素材の種類が増えすぎないよう、素材を複数のアイテムで使い回しています。

本ドキュメントは検討結果であり、確定仕様書ではありません。`RecipeSystem.md` で検討したレシピの仕組み
（工程・素材要求）を前提としていますが、本書では具体的な工程分割やYAMLの記法までは踏み込まず、
「何を、何から作るか」という内容面の整理に留めています。

**一覧のアイテムは、既定では未実装の案です。** 投入済みのものだけが、各節の本文で「実装済みです」と
定義ファイルの名前を添えて名乗ります（[`../DocumentStyle.md`](../DocumentStyle.md) 4節）。

## 0. 素材一覧

このアイテム群全体で使う原材料は、以下の9種類（＋既存の食料資源2種類の流用）に絞っています。

| 素材 | 主な入手方法 | 用途 |
|---|---|---|
| 石 | 採取 | 刃物・打撃部（無加工〜柄付き） |
| 木 | 採取・若木を切る・伐採 | 柄・軸・掘り棒・槍の柄・火起こし具・板 |
| ヤシの葉 | ヤシの木から採取 | 編んだ葉（籠・壁・屋根の共通素材） |
| 植物繊維 | バショウ属の草を切り倒し、茎から掻き取る／ヤシの実の皮を叩き解す（コイア。皮を剥ぐのに刃物が要る） | 糸・紐・ロープ（柄の固定・縫製）、編み材、罠 |
| 生皮 | 狩猟 | 衣類・袋（未処理、劣化しやすい） |
| 樹皮 | 広葉樹から剥ぐ（刃物が要る） | なめし剤（生皮→なめし革への加工に使用） |
| 獣骨・角 | 狩猟 | 掘削具の頭部（シャベル・ピック）、骨針 |
| 銅鉱石 | 採掘 | 青銅の材料 |
| 錫鉱石 | 採掘 | 青銅の材料 |
| 粘土 | 採取 | 土器 |
| （ヤシの実） | 既存の食料資源を流用 | 容器（無加工） |
| （竹） | 既存の資源を流用と想定 | 容器（無加工） |

**「木」は入手方法で別々のアイテムに分かれます。** 用途で分けても、同じ探索から何種類もこぼれてくるだけで、
プレイヤーが選ぶ場面は増えません。分けるのは、採るのに要る物が変わるときだけです。

| アイテム | 入手 | 用途 |
|---|---|---|
| 小枝 | 地面で拾う（道具不要） | 焚き付け・結び・きりもみ式の錐・燃料 |
| 太い枝 | 地面で拾う（道具不要） | 斧・ハンマー・シャベルの柄、突き銛 |
| 長い棒 | **若木**を刃物で切る | 槍・掘り棒の柄 |
| 丸太 | 伐採、または海岸へ打ち上げられた流木の幹の玉切り（どちらも斧が要る） | 建材 |

**長い棒は拾えません。** まっすぐな2mの枯れ枝は都合よく落ちていない（反るし腐る）ので、生きた若木を切って
採ります。刃物 → 若木 → 槍という順になり、狩猟が道具の後ろへ並びます。**若木**は土地の探索で見つかる設置物で、
ヤシの木と同じ採取ポイントとして扱います。

**長さの違いはかさ（`volume`）で効かせます。** 2mの棒は持ち歩くのも籠へ入れるのもかさばる、という形で
柄の材料と差が出ます（[`Containers.md`](./Containers.md)）。

**大きさの違う木を兼ねさせません。** 手に持って柄にする物と住居に組む物は大きさが2桁違うので、太い枝を
大きくして丸太を兼ねさせることはしません。柄にする70cmの太い枝と2mの長い棒も同じ理由で別物です。

**なめし革**（生皮＋樹皮）・**青銅**（銅鉱石＋錫鉱石）・**板**（木を楔で割って作る）・**編んだ葉**（ヤシの葉を編む）は、
それ自体を他のレシピの材料として使う**中間素材**として扱います。板は鋸を必要とせず、石の斧と楔で割る（riving）
ことで作れます。編んだ葉は素手でも作れ、刃物で中軸を割ると同じ葉から2枚とれます（`weaving.yaml`）。

## 1. 道具（採取・加工用）

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | ただの石 | 石 | 加工なし。叩き石として使用 |
| 1 | 大きな石 | 石 | 数回打ち欠いただけの、柄なしで握って使う石器 |
| 1 | 石の刃物（ナイフ） | 石 | 剥片をそのまま使用。柄は不要 |
| 2 | 石の斧 | 石 + 木 + 植物繊維 | 柄付け技術（紐で固定）が必要 |
| 2 | 石のハンマー | 石 + 木 + 植物繊維 | 石の斧と同じ柄付け技術。打撃部の形状違い |
| 3 | 青銅の斧 | 青銅 + 木 + 植物繊維 | 石の斧と同じ柄付け技術で頭部を青銅に置き換え |
| 3 | 青銅のナイフ | 青銅 + 木 + 植物繊維 | 柄をつけて強化した上位のナイフ |

**打ち欠いた石器と青銅の間に、磨製の段は置きません。** 挟んでも開くものが1つも無いためです——丸太も
板も柄付けもグレード2の石の斧で出ており（[`ContentSkeleton.md`](./ContentSkeleton.md) 4節の系統4）、
次に線を引くのは青銅です。磨いて変わるのは切れ味と欠けにくさですが、前者は速さなので段ではなく幅で
（同2節）、後者は**道具が使って傷む仕組みがこの世界に無い**（[`../engine/DurabilitySystem.md`](../engine/DurabilitySystem.md)
が見ているのは天候と腐敗だけです）ので、どちらも線を引きません。

### 1.1 火起こし具

同じ目的に対して、「材料が要らないが遅い」と「材料が要るが速い」を並べています。

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | きりもみ式の火起こし具 | 木（小枝と太い枝） | 手で揉む。素材が拾った木だけなので、道具も紐も要らない |
| 2 | 弓錐式の火起こし具 | 木 + 植物繊維 | 紐を弓に張って錐を回す。着火が速く、湿気にも強い |

きりもみ式が道具も紐も要求しないことが、火スキルの最初の一歩を保証しています
（[`../engine/SkillSystem.md`](../engine/SkillSystem.md) 3.2 節）。

### 1.2 縫製・罠

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | くくり罠 | 植物繊維 | 小動物用。武器なしで狩猟を始められる |
| 1 | 骨針 | 獣骨・角 | 縫製に要る。小動物の小骨からでも作れる |

くくり罠と骨針は、繊維だけを起点に **繊維 → 罠 → 小動物 → 小骨・小さな生皮 → 骨針 → 縫製** という浅い経路を
作ります。槍も掘削具も経由せずに皮革へ到達できるため、大型動物の狩猟（槍が要る）は小動物の上位として
位置づきます。

## 3. 武器

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | 木の槍 | 木（長い棒） | 先端を尖らせ火で炙って硬化。掘り棒と同じ技術 |
| 2 | 石鏃の槍 | 木（長い棒） + 石 + 植物繊維 | 石の刃物を柄付け技術で穂先として固定 |
| 3 | 青銅の穂先の槍 | 木（長い棒） + 青銅 + 植物繊維 | 同じ柄付け技術で穂先を青銅に |

石のハンマーは打撃武器（棍棒相当）としても兼用できるため、武器専用の棍棒は別途用意していません。

**石の斧（1節）と槍は、武器としては実装済みです**（`src/assets/world-codex/tools.yaml`）。一撃がどこへ入るかの
重み配分だけが違い、斧は打ち砕く側・槍は突き通す側に寄っています
（[`../engine/HuntingSystem.md`](../engine/HuntingSystem.md) 1.2 節）。**石の斧はレシピも入りました**——
太い枝を削って柄をこしらえ、尖った石を紐で締め上げる2工程で、上の表の「石 + 木 + 植物繊維」がそのまま
工程になっています。**槍のレシピはまだありません**（柄になる長い棒が無いため）。

**槍は刃物の後ろに並びます。** 柄になる長い棒が若木を切って採る物なので、刃物を作るまで槍は作れません。
罠（1.2節）が刃物を要らないので、狩猟の入口そのものは塞がりません。

## 4. 容器

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | ヤシの実の器 | ヤシの実 | 半分に割るだけ。多少の防水性あり |
| 1 | 竹筒 | 竹 | 節の間を切り出すだけ。水を運ぶのに優秀 |
| 2 | 皮袋 | 生皮 + 植物繊維（縫製、骨針が要る） | 生皮のままなら劣化・腐敗しやすい |
| 2 | 皮袋（なめし革） | なめし革 + 植物繊維（縫製、骨針が要る） | 同じ形状だが長持ち。なめし革を使った上位互換 |
| 3 | 土器（本焼き） | 粘土 | 高温での焼成が必要。真に長持ちし水も保持できる |

**天日干しの素焼き粘土は水には向きません**（濡れると崩れる）。土器を作るなら本焼きまで行う前提とし、
素焼きの中間アイテムは別途用意していません。

**土器は実装済みです**（`src/assets/world-codex/pottery.yaml`）。草地・森林・密林の探索で粘土が
見つかり、粘土2個を成形して未焼成の壺にし、粘土3個で築いた**使い捨ての覆い焼きの炉**で焼くと甕に
なります。**乾かすのは工程ではなく、置いておく時間です**（1日で乾き切ります）。濡れたまま焼くと、
残った水が水蒸気になって器を割ります——割れる確率は残った水そのもので、乾き切っていれば必ず成功します。**料理の炉では焼けません**——石囲いの炉に壺を燃料ごと埋める空間が無いためで、
焼成の炉は火力ではなく「何を火に載せられるか」の枠で分けています
（[`../engine/FireSystem.md`](../engine/FireSystem.md) 6 節）。

**焼成の設備は覆い焼きだけで、上位の恒久窯は足しません。** 焼成レンガの窯は、それを焼く窯が先に要る
（覆い焼き → レンガ → 恒久窯）ので順序ごと足すことになりますが、**それで開くのは「同じ素焼きを、
覆いを作り直さずに焼ける」ことだけです**——素焼きに要る600〜900℃は覆い焼きで届き、窯が狙う1100℃超は
炻器（焼き締め）のためのもので、水を溜める壺には要りません。**製錬に要る高温の炉は、これとは別の
構造物です**——足すなら採鉱・製錬の側が持ちます（[`ContentSkeleton.md`](./ContentSkeleton.md) 4節の
系統4）。

本節は液体を保持できる容器だけを扱います。固形物を入れる
かご・箱・そりは [`Containers.md`](./Containers.md) を参照してください（防水加工したかごは7節のとおり
本書のスコープ外です）。

容器自体が耐火性を持たなくても、焼け石を投入する「石焼き調理」で煮炊きは可能という想定です（詳細な調理系の
仕組みは別途検討）。

## 5. 衣類

| グレード | アイテム | 素材（レシピ） | 備考 |
|---|---|---|---|
| 1 | 束ねた葉の衣類 | ヤシの葉 + 植物繊維 | 加工ほぼゼロ |
| 1 | 生皮の衣類 | 生皮 | 縫製なしでそのまま身につける想定。劣化しやすい |
| 2 | 編んだ葉の衣類 | 編んだ葉 + 植物繊維 | 編み技術が必要 |
| 2 | なめし革の衣類 | なめし革 + 糸（縫製、骨針が要る） | 長持ちし、快適性も高い |

布（紡績＋機織り）は対象外としています（7節参照）。

**4種とも実装済みです**（`src/assets/world-codex/clothing.yaml`）。作った物はキャラクタの装備スロットへ
入れて着られ、出せば脱げます。**4種とも `covers: [body]` と `layer: base` を持ち、4種で同じ値です**
（[`../engine/GameElementDefinition.md`](../engine/GameElementDefinition.md) 7.5 節の `covers`/`layer`）
——**同じ部位を同じ階層で覆うので排他になり、同時に着られるのは1着だけです。** 部位を分けるのも
重ね着も、衣類が増えてからでよいという判断です。
**身につけられることは、4種が `equippable` タグで名乗ります。装備スロットはこのタグだけを受け入れます**
——石もヤシの実も身につけられません（`characters/player_character.yaml`）。衣類でない装備（背負う
入れ物、[`Containers.md`](./Containers.md)）が入るなら、それも同じタグを名乗ります。タグが言うのは
衣類であることではなく、身につけられることです。

**保温の効果はまだありません。** 受け取る側（キャラクタの `warmth` と `chill_point`、
[`Characters.md`](./Characters.md)）は入りましたが、衣類が `chill_point` を押し下げる側がまだ無いため、
着ても値は何も動きません——寒さを防ぐ手段は今のところ火と洞窟だけです
（[`../engine/VitalsSystem.md`](../engine/VitalsSystem.md) 8.3 節）。

**なめし革を作る工程も入りました**（`clothing.yaml` の `tanned_leather`）。広葉樹から**立ったまま樹皮を
剥ぎ**（刃物が要る。`timber.yaml`）、毛と肉を落とした生皮1枚を樹皮3巻きの渋に漬けると、なめし革1枚に
なります。**ひと剥ぎが革1枚ぶん**で、木は剥いでも残ります。所要は2工程で計480分——同梱の世界で最も長い
1つの作業（畑を起こす480分）に並べた値で、実際のなめしは日をまたぐ漬け込みですが、途中で止められない
工程として持つ以上は伸ばしていません。

## 6. 素材の再利用状況

各素材が何種類のアイテムに使われているかの一覧です。

| 素材 | 使用アイテム数（概算） |
|---|---|
| 石 | 4（無柄3種＋石の斧の材料） |
| 木（小枝） | 3（きりもみ式・弓錐式の火起こし具・燃料） |
| 木（太い枝） | 5（石の斧・石のハンマー・青銅の斧・青銅のナイフ・青銅のシャベルの柄） |
| 木（長い棒） | 4（木の槍・石鏃の槍・青銅の穂先の槍・掘り棒） |
| 木（丸太） | 建材（[`Dwellings.md`](./Dwellings.md)）と板の材料 |
| 植物繊維 | 10（柄の固定・縫製・編み物・衣類の大半・弓錐・くくり罠） |
| 生皮 | 2（皮袋・衣類。なめし革の元にもなる） |
| 樹皮 | 1（なめし革への加工にのみ使用） |
| 獣骨・角 | 3（シャベル・ピック・骨針） |
| 銅鉱石／錫鉱石 | 4（青銅の斧・ナイフ・シャベル・槍の材料） |
| 粘土 | 2（土器と、それを焼く覆い焼きの炉） |
| ヤシの実／竹 | 各1（既存資源の流用） |

木・植物繊維・石が多くのアイテムで共有される中心素材となり、専用素材（樹皮・粘土）は最小限に抑えられています。
粘土は [`Dwellings.md`](./Dwellings.md) の土壁でも使うため、用途は土器だけではありません。

## 7. 除外・保留にした要素

一人でのサバイバル・素材種類の抑制という方針から、以下は本書のスコープ外です（将来の拡張候補）。

- **布（紡績＋機織り）**: 専用の道具一式（紡錘、織機）が必要で、なめし革で十分快適性を確保できるため対象外。
- **鉄**: 精錬に必要な高温・炉が一人のサバイバルでは非現実的なため、青銅を上限とする。
- **柄付け・容器の防水における樹脂（松脂等）の使用**: 紐（植物繊維）だけで柄付けは成立するため、樹脂は使わない
  前提。これに伴い防水加工したかご（編みかごへの樹脂塗布）も一覧から除外。
- **ひょうたん（gourd）容器**: ゲーム内の植生に含めるかどうかが未確定なため保留。
- **自然銅の冷間鍛造品**: グレード数を抑えるため、銅を個別アイテム化せず、青銅の材料（銅鉱石）としてのみ扱う。

## 8. 未決事項

- 各アイテムの具体的な効果値（防御力・耐久値・サイズなど）は未定義。`GameElementDefinition.md` の
  `props`/`passive`（6節・8節）・`ContainerSystem.md` のサンプルに準じて別途定義する。
  重さ（`weight`、単位はg）だけは、既にゲームへ登場しているアイテムには実物の目安で入れてある
- `RecipeSystem.md` の `steps`（工程分割）・`duration`（所要時間）を、本書のどのアイテムにどう割り当てるか
- 青銅という中間素材が、`RecipeSystem.md` の「成果物の `object_defs` にレシピを埋め込む」設計上、
  それ自体を1つの完成品（`object_defs`）として扱ってよいか。**なめし革では確認済み**——中間素材を
  ただの `object_defs` として置き、そこにレシピを埋めるだけで、材料としても成果物としても通った
  （5節）。青銅も同じ形になるはずだが、鉱石・製錬の側がまだ無い

**塩は天日で採る。海水を煮詰める形は採りません。**
[`ContentSkeleton.md`](./ContentSkeleton.md) 4節の保存の段4にあたります。

| 物 | 素材（レシピ） | 備考 |
|---|---|---|
| 塩田 | 石4個（4時間） | 浅い盤。海に面した土地でしか海水を汲めない。設置物 |
| 塩 | 塩田で採れる | ひと掴み。1つで食べ物1つを塩蔵できる |

**塩田は罠・畑とまったく同じ「仕掛けて待つ」設備です**（[`../engine/TrapSystem.md`](../engine/TrapSystem.md)・
`farming.yaml`）。海水を1杯汲んで張り（15分、8杯まで）、強い日差しが24 tick当たるたびに1杯ぶんが塩1つに
なります。24 tickは砂浜の晴れならちょうど1日ぶんで（時間帯は`salt.yaml`の`drying_remaining`）、
**日陰の海岸や曇りの続く日は届く時間が短くなるぶんだけ遅くなります**。雨は張った海水を薄めるので、
乾きかけは押し戻されます。

**煮詰める形を退けた理由は、要る設備ではなく置き場所です。** 海水を器へ汲む口も、煮詰め切った器から塩を
出す口も、器の側（`liquid_containers.yaml`）に置くことになりますが、甕の中身は既に「尽きたら空の容器へ
戻る」を持っているため、そこへ「尽きたら塩が残る」を重ねられません。焼け石
（[`../engine/FireSystem.md`](../engine/FireSystem.md) 9.1節）が沸かせるのも1個につき1杯ぶんなので、
4Lを煮詰める燃料の勘定を新しく持ち込むことになります。

**塩蔵は、腐敗の速さを既にある段の中で移すだけです**（[`../engine/DurabilitySystem.md`](../engine/DurabilitySystem.md)
3節）。塩を食べ物へ重ねると、通常温度で減る速さが最も遅い段（芋と同じ20日）へ移ります。新しいレートは
持ち込みません。

- **無事な物にしか効きません。** 塩は腐敗を止めるだけで、進んだぶんは戻りません。
- **屋外の上乗せ（-1）はそのまま効きます。** 塩漬けでも外へ置けば6.7日に落ちるので、塩は温度と湿りの
  代わりにはなりません。
- **漬かるのは生のままの物だけです**（`foods.yaml` の `cure` 軸）。焼くのは食べるための工程なので、
  焼いた物を保たせる形は作りません。
- **隔てるものがある物も漬かりません。** 殻の中のヤシの実・海鳥の卵・土の中の塊茎（タロイモ）は、
  最も遅い段に居ること自体がその殻や皮から出ているので、塩の仕事は既に済んでいます。**軸を持つのは、
  漬けると実際に速さが移る食べ物だけです**（`tests/world-codex/saltYaml.test.ts` が全数を検査します）。

**実装済みです**（`src/assets/world-codex/salt.yaml`）。**塩の生理的な必要性（ナトリウム）は扱いません**
——舐めて体の値が動く仕組みが無いため、塩は食べ物になりません。**燻し小屋（保存の段3）は本節の
対象外です。** 同じ系統ですが別の設備で、塩蔵とは重ねて効きます。**干し場（段2）は10節が持ちます。**

【いつか: 燻製】 煙で保たせる道は、塩蔵の20日で島の暮らしが回るので後から足します
（[`Someday.md`](../Someday.md)）。

## 10. 干し場

**干し場が開けるのは、腐敗の最も速い段の食べ物——生肉・獣の死体・ヤシガニ・海藻——を干物にできる
ことです。** [`ContentSkeleton.md`](./ContentSkeleton.md) 4節の保存の段2にあたります。

**生のまま腐る `spoils_fast` は、これで全数です**（型では7つ——`animals.yaml` の `raw_meat` と死体4種、
`foods.yaml` の `coconut_crab`、`voyage.yaml` の `seaweed`）。**焼いた物も同じ段に居ますが干せません**
——焼くのは食べるための工程なので、焼いた物を保たせる形は作らない、という9節の塩蔵と同じ切り分けです。

| 物 | 素材（レシピ） | 備考 |
|---|---|---|
| 干し場 | 太い枝6本 + 縄1本（2時間） | 立てた枝に縄を張り、切り分けた食べ物を掛ける棚。設置物 |
| 干物 | 干し上がった食べ物 | 腐敗が最も遅い段（20日）へ移る。別の型は作らない |

**干す仕掛けは1つだけです。** 食べ物を日の当たる地面へ並べるか干し場に掛けると「干し上がるまでの
残り」が **72** で立ち、**強い日差しが当たる tick だけ減ります**。境目は塩田の `drying_remaining` と
同じ1つ（9節）なので、曇れば止まり、雨は乾きかけを押し戻します。**残りを持つのは食べ物で、干し場が
変えるのは1 tick に減る量1つだけです**——地面に並べると片面にしか日と風が当たらないので `-1`
（72 tick かかる）、干し場に掛けている間は上乗せの `-2` が重なって `-3`（24 tick）。**途中で
掛け替えても進んだぶんは残ります**——残りが食べ物に付いているので、場所が変わるのは減る速さだけです。
**しまってある間は乾きも戻りも起きません**——手に持っていても籠の中でも、並べるか掛けるかしなければ
日差しも雨も届きません。

**線を引いているのは、この速さではなく腐敗のほうです。** 干している間も食べ物は屋外に居るので、
屋外の上乗せ（-1）を受けたまま乾きと競走します（[`../engine/DurabilitySystem.md`](../engine/DurabilitySystem.md) 3節）。
**日差しの量と経過時間は別の物差しです**——境目を超えるのは開けた土地の晴れでも1日に24 tick だけ
なので（`salt.yaml` の `drying_remaining`）、地面の72 tick は経過時間では3日ぶんにあたります。

| 分類 | 屋外の寿命 | 地面に並べる（72 tick） | 干し場に掛ける（24 tick） |
|---|---|---|---|
| 生肉・死体・ヤシガニ・海藻 | 2日 | **届かない**（腐り切るまでに貯まるのは48 tick まで） | 干し上がる |
| 空心菜・バナナ・ヤシの果肉とゼリー | 3.3日 | 晴れが3日続けば干し上がる | 干し上がる |
| 芋・ヤシの実・卵 | 6.7日 | 既に最も遅い段なので干す意味が無い（軸を持ちません） | 同左 |

**速くなること自体は値打ちではありません**（[`../concept/DesignPrinciples.md`](../concept/DesignPrinciples.md)
の「悪条件は、効率を下げるのではなく、できる／できないの線で効かせる」節）。ここで速さが値打ちに
なるのは、腐敗が先に線を引いていて、**その線を跨ぐのが干し場だけ**だからです。

**候補のうち2つは退けました。**

- **屋根を掛けて雨の日でも干せるようにする案。** 屋根は日差しも止めます——守られた場所
  （`sheltered`、[`../engine/ContainerSystem.md`](../engine/ContainerSystem.md) 6節）では雨が乾きを
  押し戻さない代わりに、そこには日が差しません（`salt.yaml` の `drying_remaining`）。**雨季に干せない
  のはそのままにします**——乾季と凪の晴れ間に干して雨季を越すのが保存の系統の形で、雨季に採れる
  時間が細ることが備蓄の理由そのものです（[`ContentSkeleton.md`](./ContentSkeleton.md) 8.1.3節）。
- **一度に干せる数を増やす案。** 地面に並べる数を縛るものがありません（`core.yaml` の `location`
  trait が配るアイテムのスロットに `cell_count` が無い）。干すためだけに土地の側へ上限を彫ることに
  なります。干し場の棚に入る数には限りがありますが、それは棚の大きさであって、干し場が開けるものでは
  ありません。

**1基で段に届きます**——縄が1本要るためで、囲いが丸太4本と縄2本で1つでも段になるのと同じ理由です
（[`ContentSkeleton.md`](./ContentSkeleton.md) 4節）。**同4節の1.17日<!-- stats: balance.yaml object_costs object=drying_rack days -->は、この1基ぶんです。**

**素手の天日干しは、干し場が建っても残ります**（[`../concept/DesignPrinciples.md`](../concept/DesignPrinciples.md)
の「後から足す手段は、既存の手段を残す強さに抑える」節）。空心菜・バナナ・ヤシの果肉とゼリーは
それで足りるので、そのために棚を組む理由がありません。**塩蔵（9節）が来ても残ります**——塩は1つ漬けるごとに1つ消え、
その塩は**海に面した土地でしか汲めない**海水を日に干して作りますが、干し場は組めば何度でも使えます。

**干物は塩漬けと重ねません。** 干すのも漬けるのも腐敗の最も遅い段へ移すだけで、そこが今ある段の端
だからです。干した物は塩と同じ `cured` タグを名乗り、**塩漬けの操作そのものが現れなくなります**
——止めているのは条件ではなく軸のほうで、**変種の変種は作らない**
（[`../engine/GameElementDefinition.md`](../engine/GameElementDefinition.md) 3.5.1節）ため、干物には
`cure` の行き先がもう残っていません（塩漬けを二度漬けられないのも同じ理由です）。**燻製（【いつか】、9節）が塩蔵と重ねて効くのは、入れるときに
塩蔵の弱体化か、どちらを選ぶかを分ける条件をセットにする前提だから**です
（[`Someday.md`](../Someday.md)）——重ねる先はその時に作られるもので、今ある端の上には無い、という
点で干物と食い違いません。

**干せるのは、干して実際に速さが移る食べ物だけです**（9節の塩蔵と同じ切り分け）——殻の中のヤシの実・
海鳥の卵・土の中の塊茎（タロイモ）は、最も遅い段に居ること自体がその殻や皮から出ているので、干す
仕事も既に済んでいます。**軸を持つのはそれ以外の11種だけです**（`tests/world-codex/dryingYaml.test.ts`
が全数を検査します）。

**据える場所は縛りません。** 樹冠の深い森・密林では境目を超える時間がほとんど無い
（[`ContentSkeleton.md`](./ContentSkeleton.md) 8.1.2節）ので、**干せないことは乾きが進まないことで
分かります**——塩田を海から離して据えられるのと同じです。

**実装済みです**（`src/assets/world-codex/drying.yaml`）。**tick の数は詰め直しました**——地面の48 は
最短30時間で貯まってしまい、生肉の屋外2日に間に合います。**腐り切るまでに貯められるのは、何時に
並べても48 tick ちょうど**なので、地面を72・干し場をその3分の1の24に置き直すと上の表の線が3つとも出ます
（`tests/world-codex/dryingYaml.test.ts` が、並べ始めの時刻を1日ぶん振って確かめます）。
**干し上がりを告げる仕組みはありません**——罠・畑・塩田と同じ沈黙なので、見に来るまで分かりません
（[`../engine/TrapSystem.md`](../engine/TrapSystem.md) 5節）。
