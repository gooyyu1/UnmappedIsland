# いつか実装したいこと

**無くても完成を宣言できるが、いつか実装したいもの**を集めます。**残りの作業量には数えません。**

無いと完成と言えないものの印は `【未実装: 識別子】` で、実体は `task` ラベルの issue が持ちます
（[`DocumentStyle.md`](./DocumentStyle.md) 4節）。本書が持つのはその外側だけです。両方を1つの印で
扱うと、**あと何が足りないのかを誰も答えられなくなります。**

- **各文書に残すのは印と短い参照だけで、中身はここにしかありません。**
- **見出しの先頭の語が識別子です。** どの文書の印とも対応しない項目、または項目の無い印があると
  `tests/docs/docReferences.test.ts` が落ちます。
- **並び順に意味はありません。** 期限も優先度も持たせません——持たせた時点で残作業の一覧になります。

## 一覧

### 月齢 — 夜の明るさを月齢で周期させる

いまは半月固定で、夜はどの時刻も暗さの底へ均されます（[`ContentSkeleton.md`](./world/ContentSkeleton.md)
8.1.1.1節）。**画面に月齢を出す形が決まっていない**ので入れません。入れると開けた土地の夜が
「歩ける／歩けない」で周期的に切り替わります——森と密林はどのみち歩けないので、効くのは開けた土地だけです。

### アチーブメント — 周回をまたぐ記録を残す

「すべての動物を飼いならす」のような達成を、棚と同じく周回をまたいで永続させます
（[`GameEndings.md`](./concept/GameEndings.md) 7節）。棚が既に周回をまたぐ動機を担っているので、無くても
終幕は成立します。保存先は棚と同じ、セーブの4スロットとは別の領域（[`SaveDataManagement.md`](./engine/SaveDataManagement.md) 棚節）。

### なめし革の帆 — 生皮の帆の上に1段置く

帆は生皮の1種（`sail_speed` +2）だけで、その上は空けてあります（[`Voyage.md`](./world/Voyage.md) 2.1節）。
なめし革が中間素材として入っていない（[`SurvivalItems.md`](./world/SurvivalItems.md) 8節）ので今は作れません。
+4 を置くと、風の悪い日ほど生皮との差が開きます。

### 明るさ条件の検査 — 条件の書き忘れを見張る

明るさの条件を書かない操作は「暗くてもできる」という意味になり、書き忘れと見分けが付きません
（[`IlluminationSystem.md`](./engine/IlluminationSystem.md) 5節）。操作の一覧を出して、明るさの条件を
持たないものを並べる検査で見張ります。遊びの側は無くても完成するので、診断の道具として後から足します。

### 図鑑の生成型 — 中身入りの容器を図鑑に載せる

「水入りの甕」のように実行時に生成される型は図鑑（`src/codex-viewer`）の一覧に無く、名指しで開く道が
ありません（[`LiquidContainerSystem.md`](./engine/LiquidContainerSystem.md) 1節）。空の容器と液体は別々に
載っているので、無くても図鑑は読めます。載せると、容器と液体の組み合わせが1ページで確かめられます。

### 洞窟内部 — 洞窟の中へ入って探索できるようにする

探索で `cave_entrance` は見つかりますが、入る先がありません。要るのは `structure_interior` スコープの
再帰生成（[`TerrainGeneration.md`](./engine/TerrainGeneration.md) 3.7節）と、内部への遷移です。入口が
見つかること自体は土地の顔になっているので、中へ入れなくても1周回は成立します。入れるときは次の3つが
同時に要ります。

- **内部の土地にも、着いた時点で分かる違う名前が要ります。** 道のカードは `fixtures` レーンの中で
  並び替えできてしまうため、名前が無いと進んでいるのか戻っているのかが読めません
  （[`DesignPrinciples.md`](./concept/DesignPrinciples.md) の「見分けの付かない場所を作らない」節）。
  現実に即して見分けが付かないままにすると、盤面が読めず判断のしようがなくなります。
- **洞窟は昼でも真っ暗です**（[`IlluminationSystem.md`](./engine/IlluminationSystem.md) 4節）。潜るには
  必ず光源が要るので、燃料の需要が一段増えます。
- **アーティファクトの出どころのうち8種類が洞窟の奥です**（[`ContentSkeleton.md`](./world/ContentSkeleton.md)
  6節の確定した配分）。中へ入れないままなら、この8種類は別の行き先へ振り替えることになります。

## 動かせなかったもの

29文書の未決事項節の約200項目は、大半がここへ移りません。**移す条件は「やるかどうかが決まって
いること」と「入れなくても今の遊びが回ること」の両方**で、片方でも欠けるものは未決事項節に残して
あります。残した理由は次の4通りです。

| 残した理由 | 例 |
| --- | --- |
| **やるかどうかが決まっていない**（大半） | 「解体して部品を回収できるか」「保存が調理から分かれるか」「密度の差を効かせるか」 |
| **やると決まっているが、値や形の選択が遊びの内容を変える** | 各スキルのしきい値、怪我の重さ・出血の配分、罠の餌の段 |
| **無いと完成と言えない**（残作業の側） | 欠乏症、槍のレシピ、湧き水から汲む操作、発見物の `volume`/`weight` |
| **未決事項ではなく、本文へ移すべき記述** | 「`weight` の合計が0のときは宣言順で先頭を選ぶ、と実装上決定した」（`GameElementDefinition.md` 17節）、「異種液体の混合は表現できない、が現状の仕様」（`LiquidContainerSystem.md` 9節） |

**3列目は本書の対象外です。** 印を付けて issue にするものですが、要否の判断を通さずに流さない決まりが
あるため（[`.claude/parallel-work.md`](../.claude/parallel-work.md) の「承認の要る未実装を、勝手に
流さない」節）、判断が要るものは issue #656 へ積んでいます。

**4列目は、決着済みなのに未決事項節に残っている記述です。** 本文の書き換えを伴うので、印の付け替えだけを
担当する本作業では動かしていません。
