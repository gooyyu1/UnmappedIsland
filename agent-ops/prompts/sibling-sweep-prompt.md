# 兄弟を探すサブエージェントへの指示

**決めごと・事実を書き換えた差分について、同じことを別の言い回しで言っている箇所を探す**係の本文。
立てるのは差分を書いた本人で、push の前に1回（`CLAUDE.md`「修正作業の進め方」3節）。

**書いた本人が grep しても兄弟が残るのは、探す語を書いた本人が選ぶから。** 選んだ語は書き換えた
文の言い回しなので、同じ主張の裏返し・そこから導いた値・別の文書での要約は網に掛からない
（`agent-ops/analysis/2026-09-08.md`・`2026-09-17.md` の `## 傾向`）。この係は**語ではなく、主張が
何についての話か（主語）で引き**、掛かった箇所を読んで同じ主張かを判定する。だから
**本人の検索語・直した理由・PR本文は渡さない**——渡すと本人の網をなぞるだけになる。挙がったものをどうするかは `CLAUDE.md` 3節。

`<差分のパス>` を埋めて渡す。差分は**まだ push していない分**——初めてなら
`git diff origin/main...HEAD`、2回目以降は前に push した版からの `git diff <前の版>..HEAD`。

---

````
差分 `<差分のパス>` が書き換えた決めごと・事実について、**同じことを別の言い回しで言っていて、
書き換えの前の版のまま残っている箇所**をリポジトリ全体から探してください。直さず、作業ツリーも
書き換えず、見つけた箇所だけを返してください。

1. **差分が書き換えた主張を、1件ずつ文に起こす。** 消した行・書き換えた行から「前は何と言って
   いたか」と「今は何と言っているか」を対で書く。数を言葉へ置き換えた・言い方を狭めた・
   根拠を差し替えた、も主張の書き換えに数える。足しただけの行は、それが前から在る記述と
   食い違うときだけ数える。
2. **主張ごとに、それが何についての話か（主語）を挙げる。** yaml のキー・関数や型の名前・
   統計の名前・節の番号と題・数値と、その数値から足し引きや半分で導ける値・場所や物の名前。
   **述語（決まる・残る・届かない、のような言い回し）では引かない**——言い回しは書き手ごとに
   違うので、引けるのは書き換えた文と同じ書き方のものだけになる。
3. **主語ごとにリポジトリ全体を引く。** `docs/`・`src/` のコメント・`src/assets/**.yaml` の
   コメント・`tests/` のコメントとテスト名・`agent-ops/`・`CLAUDE.md`・`.claude/`。
   **書き換えた節・ファイルへのリンクと節番号の参照**も引く。`agent-ops/analysis/`・
   `agent-ops/decisions/`・`DesignNotes.md` の事例は当時の記録なので除く。
4. **掛かった箇所を前後ごと読み、前の版の主張を言っているかを判定する。** 同じ語を使っている
   かではなく、**読んだ人が前の版を信じるか**で決める。裏返し（「Aなので B が通る」と
   「B が塞がっている」）・帰結（「上げると〜が破れる」）・前の版の値から導いた数・要約も当たる。
   今の版と同じことを言っているものは挙げない。

返すのは、当たった箇所だけを1件1行で:

    <ファイル>:<行> — <前の版のどの主張を言っているか>（<その箇所の文を短く引く>）

当たるものが無ければ「無い」とだけ返す。1で起こした主張の一覧は、最後に短く添える。
````
