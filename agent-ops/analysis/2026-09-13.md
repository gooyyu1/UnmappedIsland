## 傾向

### レビューが挙げたスメルは、同じPRの後の周で消えていることがある

**この帯でいちばん多かった形。** マージ済みPRのコメントは周ごとに積まれるので、1周目のレビューが
挙げたスメルを2周目・3周目の著者が直していることがある。**コメントだけを読んで issue にすると、
受け取った側は直っている箇所を探すことになる。**

実測（この回で当たり直した範囲）——取り下げたのは PR #2105 の3件・PR #2106 の2件・PR #2110 の1件・
PR #2117 の2件・PR #2082 の2件・PR #2080 の1件・PR #2074 の1件・PR #2066 の2件・PR #2063 の1件・
PR #2059 の3件・PR #2076 の1件で、**読んだ58件のうち19件**が「コメントには在るが現物には無い」
だった。**多かったのは、著者が
「スメルも直しました」と別のコメントで報告している形**（PR #2105・#2117・#2049 など）と、
**次の周のレビューが「前の周のスメルは消えている」と書いている形**（PR #2082・#2074・#2066・#2059）。

### 1つのPRの周をまたいで、同じ根の指摘が別々のスメルとして出る

PR #2110 の「上限960 vs 2880」（1周目）と「武器に `too_worn` が無い」（3周目）、PR #2131 の
「`Voyage.md:601` の幅」（1周目）と「`:236`/`:239` の幅」（2周目）、PR #2080 の暦の直書き（3周とも）。
**1本のPRのコメントを時系列で並べないと、同じ根だと分からない。**

### 「全体について断定したが、端で崩れる」記述が、この帯の文書のPRに繰り返し出た

PR #2141（押し流されるのは雨季だけ／押し流しはほぼ必ず横断中）・PR #2126（この節だけが／表に行が無い）・
PR #2098（生かす側が常に高くつく）・PR #2114（1本ごとに2時間ずつ）・
PR #2106（4日ぶんの側／長い側）。**PR #2106 では同じ形が2周続けてレビューを止めており**、著者が
「幅で書いた主張は両端で確かめる」という原則として受け取っている。#2168 として切った。

### 値の二重の出どころが、コード・文書・テストのどこにも出る

PR #2080（暦を `src/`・`tests/`・yaml・docs が別々に直書き）・PR #2117（`EMPTY_CELL_CYCLE_MS` を
`CardView.md` が書き写す）・PR #2131 と PR #2097（生成物から導いた幅に印を置けない）・
PR #2098（材料の照合が4つだけ）。
**出どころを1つに寄せたPRの直後に、寄せきれなかった側がスメルとして出る**のが共通していた。
