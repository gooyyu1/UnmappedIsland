## エージェントの解釈

- 自動実行デーモン関係のファイルが `.claude/` の直下に平置きされているのは、整理されていない状態
  として直す。
- `.claude/` に置くのは Claude Code でしか意味のないものだけ。エージェントを選ばないスクリプトは
  `scripts/agent/`、自動実行のようにエージェントが使うのではないものは `scripts/daemon/` のような
  別の置き場のほうが適切でありうる。
- セッションへ渡すプロンプトのひな形も、判断の記録も、Claude Code 専用ではないと見る
  （＝`.claude/` に留める理由にならない）。
- 移動先を作るために「PR無しで push してよいフォルダ」を増やしてよい。
- 「終わったらファイルごと消す」と自分で書いた文書は、終わったら実際に消す。
- 一回きりの記録と、次も使える方針は、同じ場所に混ぜない。記録の側はフォルダ名の日付などで過去の
  ものだと分かるようにし、方針の側は残す。
- 方針のうち、コーディング規約やアーキテクチャドキュメントに属するものは、そちらへ反映する。
- 複雑な作業は、このセッションで抱え込まず issue を立てて配ってよい。
